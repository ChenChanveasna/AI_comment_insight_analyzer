# AI Comment Insight Analyzer

AI Comment Insight Analyzer is a simple web-based project that helps users understand the overall sentiment of comments from a YouTube video.

The user pastes a YouTube video URL into the system, and the application retrieves the comments, cleans the text, analyzes sentiment, and presents the results in a clear and easy-to-understand way.

## Features

- Input a YouTube video URL
- Retrieve comments from the video
- Clean and preprocess comment text
- Analyze sentiment as positive, negative, or neutral
- Display basic charts and summary statistics
- Generate a short AI feedback summary
- Extract common keywords or topics
- Identify common praise and complaints

## Purpose

This project was developed as part of an AI Fundamentals final project.  
Its goal is to demonstrate how Artificial Intelligence and Natural Language Processing can be used to turn large amounts of online comments into useful insights.

## How It Works

1. The user enters a YouTube video URL
2. The system retrieves comments using the YouTube Data API
3. The comments are cleaned and preprocessed
4. Sentiment analysis is performed
5. The results are displayed through charts, summaries, and keyword insights

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask or FastAPI)
- Data Processing: Pandas, NLP libraries
- Visualization: Chart.js
- API: YouTube Data API

## Project Scope

This project focuses on a simple and practical workflow:
- analyze YouTube comments only
- provide sentiment insights
- show useful summaries and visual results

It is intentionally kept lightweight and realistic for a student team project.
